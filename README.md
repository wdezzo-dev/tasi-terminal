# tasi-terminal
**Tasi Terminal** هو لوحة معلومات ثنائية اللغة (عربي/إنجليزي) لتحليل الأسهم بتصميم طرفي (Terminal). يركز على سوق الأسهم السعودية (تاسي) والأمريكية (S&P 500)، ويستخدم "نقاط التجميع" الخاصة به لتحديد الأسهم التي يتم تجميعها من قبل الأموال الذكية.

## المميزات
1. **تغطية سوقين** - تاسي (251 سهم) + S&P 500 (503 سهم) = 754 سهماً
2. **نظام نقاط التجميع (0-100)** - خوارزمية خاصة:
   - انحدار OBV (50%) - زخم حجم التداول
   - نسبة الحجم (30%) - الحجم مقابل متوسط 20 يوم
   - القرب من الدعم (20%) - مدى قرب السهم من أدنى 20 يوم
   - قاعدة 50 نقطة
3. **5 تصنيفات** - تجميع نشط، تصريف، تشبع شرائي، تشبع بيعي، محايد
4. **مؤشرات فنية** - RSI14، نسبة الحجم، OBV Slope، ATR، دعم/مقاومة
5. **أهداف سعرية** - وقف خسارة + 3 أهداف ربح لكل سهم
6. **أفضل 5 فرص** - أعلى 5 فرص تجميع معروضة في الأعلى
7. **بحث فوري** - بالرمز أو الاسم مع تمرير سلس وإبراز
8. **حالة السوق الحية** - "لحظي أثناء التداول" / "إغلاق رسمي"
9. **تجميع قطاعي** - متوسط نقاط التجميع لكل قطاع
10. **تحديث كل 30 دقيقة** - أثناء ساعات التداول


## تدفق العمل
```
GitHub Actions (كل 30 دقيقة أثناء التداول) →
  scripts/fetch_data.py →
    قراءة 754 سهماً من SECTORS المضمن →
    yfinance لكل سهم →
    RSI, OBV Slope, ATR, دعم/مقاومة →
    calculate_accumulation_score() →
    تصنيف (5 فئات) →
    توقف خسارة + 3 أهداف →
    تجميع قطاعي ← كتابة data/data.json
    git commit + push

متصفح المستخدم →
  index.html →
    fetch(data.json) →
    عرض تبويبات السوق →
    أزرار القطاعات →
    بطاقات الأسهم →
    البحث الفوري
```
